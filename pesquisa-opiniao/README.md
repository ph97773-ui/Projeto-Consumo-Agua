# 📊 Pesquisa de Opinião

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white) ![GitHub](https://img.shields.io/badge/GitHub-projeto-181717?logo=github&logoColor=white)

## Sobre o projeto

Este projeto foi desenvolvido para uma atividade de Desenvolvimento de Sistemas I. A empresa fictícia TudoWeb quer descobrir como os clientes avaliam o atendimento recebido.

O programa cadastra o nome, a idade e a opinião de cada entrevistado. As opções de opinião são:

- 1 - Excelente
- 2 - Bom
- 3 - Ruim

Na execução normal, são cadastrados 50 entrevistados. No final, o programa mostra a quantidade de respostas **EXCELENTE** e **RUIM**.

## Como executar

Abra o terminal nesta pasta e execute:

```bash
python app.py
```

Depois, informe os dados solicitados pelo programa.

## Teste com 10 entrevistados

O arquivo `teste_10.py` faz um teste automático com 10 pessoas para conferir se a contagem está correta:

```bash
python teste_10.py
```

O teste utilizado possui 4 respostas excelentes, 2 respostas ruins e 4 respostas boas.

## Arquivos

`app.py` contém o programa principal.

`teste_10.py` contém o teste solicitado com 10 entrevistados.

A pasta `imagens` contém os prints do código e da execução.
